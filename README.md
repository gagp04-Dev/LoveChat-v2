# LoveChat

LoveChat is a cross-platform private messaging application built with .NET MAUI and C#.

The project focuses on creating a simple one-to-one communication experience with support for multimedia messaging and real-time communication.

## Features

- One-to-one messaging
- Image sharing
- Voice messages
- Voice and video calls
- Cross-platform interface

## Technologies

- C#
- .NET MAUI
- XAML
- MVVM
